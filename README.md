# Security Library

Librería de seguridad para aplicaciones Spring Boot que centraliza la autenticación y autorización mediante JWT para arquitecturas basadas en microservicios.

## Descripción

Este proyecto proporciona componentes reutilizables para implementar mecanismos de seguridad de forma consistente entre diferentes microservicios.

Incluye funcionalidades para autenticación mediante JWT, validación de tokens y control de acceso basado en roles mediante anotaciones personalizadas.

## Características

- Generación y validación de JWT.
- Verificación de autenticación.
- Autorización basada en roles.
- Anotaciones personalizadas para control de acceso.
- Integración reutilizable entre múltiples microservicios.

## Tecnologías utilizadas

- Java
- Spring Boot
- JWT
- Maven
